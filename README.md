# 色光與視覺實驗室 v1.2｜粉彩柔色版

國中生物教學用網站，繁體中文，延續已驗收 v1.1 極簡介面。

- **色光三原色**：三束 RGB 色光在黑色實驗區部分重疊。以紅、綠、藍三條滑桿分別控制亮度 0–100%。黑底刻意保留，以清楚呈現色光加法混合。
- **視覺負片後像**：六種刺激顏色，10 或 15 秒觀察；色塊消失後是純白色 `#FFFFFF` 的觀察區與定位十字，不會自動繪出假後像。
- **新介面**：背景、面板、頁籤、按鈕改成淡粉、霧紫、薄荷綠系；功能、文案與操作模式沿用 v1.1。
- **返回首頁**：原有 `home-button.js` 原封不動保留，可返回「剛剛數位小教室」。
- **PWA**：首次連網載入並成功快取後，支援離線使用。

## 上傳 GitHub Pages

1. 解壓 ZIP。將解壓後看到的 **全部檔案與 `icons/` 資料夾** 直接放入儲存庫根目錄，不要再包一層資料夾。
2. 在 GitHub → Settings → Pages 選擇由 `main` 的 `/ (root)` 部署。
3. 開啟對應的 GitHub Pages 網址即可使用。如果先前安裝過同站 PWA，請連網重新整理，以載入更新後的快取。

## 檔案內容

- `index.html`：介面與全部互動
- `home-button.js`：沿用已驗收的返回入口首頁按鈕
- `manifest.webmanifest`、`service-worker.js`：PWA 安裝及離線快取
- `icons/`：網站圖示

提示：實際後像與螢幕、環境照明和個人視覺適應有關；本工具不提供醫學測量。
